# Iconos de proveedor

- `claude.png`: mascota Clawd de Claude Code, vía [dashboard-icons](https://github.com/homarr-labs/dashboard-icons). Marca de Anthropic.
- `copilot.png` / `copilot-dark.png`: logotipo de GitHub Copilot, vía [dashboard-icons](https://github.com/homarr-labs/dashboard-icons). La variante `dark` es la versión clara para fondos oscuros. Marca de GitHub.
- `opencode.png`: icono de la app OpenCode, vía [opencode.ai](https://opencode.ai). Marca de OpenCode/Anomaly.
- `litellm.png`: icono abstracto de nodos conectados, generado para identificar el endpoint LiteLLM; no es un logotipo oficial.
- `claude-menu.png`, `copilot-menu.png`, `opencode-menu.png`, `litellm-menu.png`: versiones monocromas para la barra de menús, con los detalles en transparencia para que macOS las adapte al tema claro u oscuro.

Los nombres y logotipos pertenecen a sus propietarios. Se usan únicamente para identificar cada proveedor dentro de la app. No están cubiertos por la licencia MIT del código.
